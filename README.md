# GitHub for Writers

A beginner-friendly manual for authors who want to version-control their manuscripts, collaborate with editors, and publish free author sites using GitHub. No code required. Plain English, step by step.

Credit Asdale Dynamics, LLC. Made by Dylan Asdale, founder of Asdale Dynamics, LLC (Indiana, formed October 2026), registered nurse turned AI author of *The Massive AI Manual* and publisher of dylanasdale.github.io.

## What's inside

- `docs/` — step-by-step beginner manuals in Markdown
- `site/` — a free, static HTML author site you can publish with GitHub Pages
- `LICENSE` — MIT License, Copyright (c) 2026 Asdale Dynamics, LLC

## Who this is for

Writers and authors who are new to GitHub. You do not need to be a programmer. You do not need to write code. This guide is written in plain English and walks you through every click and command.

## What you will learn

1. Create a GitHub account and a repository for your manuscript
2. Save versions of your book as you write (version control)
3. Invite an editor to review and comment on your work
4. Publish a free author website with GitHub Pages
