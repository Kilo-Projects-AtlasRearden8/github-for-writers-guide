# Welcome to GitHub for Writers

You are a writer, not a programmer. You do not need to write code to use GitHub. This manual walks you through everything in plain English, one step at a time.

## What GitHub does for authors

Think of GitHub as a combination of three tools you already understand:

1. **A filing cabinet** — it stores your manuscript files online.
2. **A time machine** — it saves every version of your book so you can go back to an earlier draft whenever you want.
3. **A shared notebook** — you and your editor can both open the same manuscript, leave comments, and suggest changes without emailing files back and forth.

## A few words before we begin

- **No secrets.** Never put passwords, API keys, phone numbers, addresses, or other personal information in files you save to GitHub. This manual does not ask you to.
- **No code required.** Every step uses buttons, forms, or simple copy-and-paste commands.
- **Go at your own pace.** If something feels unfamiliar, that is normal. Re-read the step, take a break, and try again.
