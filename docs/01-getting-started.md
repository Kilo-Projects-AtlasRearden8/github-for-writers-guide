# Step 1: Getting Started with GitHub

In this step you will:
1. Create a free GitHub account
2. Create a repository (a project folder) for your manuscript
3. Upload your first chapter or document

## Part A: Create your GitHub account

1. Open your web browser and go to **github.com**.
2. Click **Sign up**.
3. Enter an email address, create a password, and choose a username.
   - Your username is public. Pick something you are comfortable sharing, like your name or your pen name.
4. Follow the prompts to verify your account. GitHub may send you an email or show you a puzzle to prove you are a person.
5. When asked, choose the **free plan**. You do not need to pay anything for this manual.

## Part B: Create a repository for your book

A **repository** (or "repo") is a folder for your project. It lives on GitHub's servers, but you can also keep a copy on your own computer.

1. After signing in, click the **+** icon in the top-right corner and choose **New repository**.
2. Give your repository a name, such as `my-novel` or `my-cookbook`.
   - Use lowercase letters, numbers, and hyphens only. No spaces.
3. Add a short description (optional), such as "My first novel draft."
4. Choose **Public** or **Private**.
   - Public: anyone can see your repository.
   - Private: only people you invite can see it.
   - Either works for this manual. Private is a good choice while you are still writing.
5. **Do not** check "Add a README file" or "Add a .gitignore" for now. We will add files ourselves.
6. Click **Create repository**.

You now have an empty repository on GitHub.

## Part C: Upload your first manuscript file

1. On your repository page, click the **uploading an existing file** link (or the **Add file** button, then **Upload files**).
2. Drag your manuscript file (for example, `chapter-1.docx`, `chapter-1.md`, or `chapter-1.txt`) into the upload area.
   - You can upload multiple files at once.
3. Below the file list, you will see a box that says "Commit changes." Type a short message, such as:
   > Add Chapter 1 draft
4. Click **Commit changes**.

Your file is now saved in your repository. GitHub remembers exactly when you uploaded it and what the file contained.

## What "commit" means

A **commit** is like saving a snapshot of your project. Each commit has:
- A message you write (for example, "Add Chapter 1 draft")
- A date and time
- A record of what changed

Later, you can look back at any commit and see what your manuscript looked like at that moment.
