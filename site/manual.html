Welcome

You are a writer, not a programmer. You do not need to write code to use GitHub. This manual walks you through everything in plain English, one step at a time.

GitHub is like a filing cabinet (stores your manuscript), a time machine (saves every version), and a shared notebook (you and your editor work together).

Step 1: Getting Started with GitHub

Create your account

  1. Go to github.com and click Sign up.
  2. Enter an email, create a password, and choose a username.
  3. Verify your account (email or puzzle). Choose the free plan.

Create a repository for your book

  1. Click the + icon in the top-right, then New repository.
  2. Name it (lowercase, numbers, hyphens only), e.g. my-novel.
  3. Add a description (optional). Choose Public or Private.
  4. Do not add a README or .gitignore yet. Click Create repository.

Upload your first manuscript file

  1. Click Add file → Upload files. Drag your manuscript into the upload area.
  2. Type a commit message, e.g. Add Chapter 1 draft.
  3. Click Commit changes.
Commit: saving a snapshot of your project with a message, date, and record of what changed.

Step 2: Version-controlling Your Manuscript

Instead of saving chapter-1-final-v2-really-final.docx, save one file and let GitHub remember every version.

Edit a file on GitHub

  1. Open your repository, click your manuscript file, then the pencil icon (Edit file).
  2. Make your changes.
  3. Type a commit message, e.g. Fix typo in Chapter 1.
  4. Click Commit changes.

View your history

  1. Open your file and click the History (clock) button.
  2. Click any commit to see that version of the file.

Restore an earlier version

  1. From History, click the commit you want.
  2. Open the file, click Edit file, type a message like Restore Chapter 1 from March 3 draft.
  3. Click Commit changes.

Good commit messages: "Add Chapter 1 draft", "Fix spelling in Chapter 3". Avoid: "changes", "final", "update".

Step 3: Collaborating with Editors

Invite your editor

  1. Go to Settings → Collaborators → Add people.
  2. Type your editor's GitHub username or email.
  3. Choose a permission: Read (proofreader), Triage or Write (editor), Maintain (co-author).
  4. Click Add collaborator. Your editor accepts by email.

Comment on specific lines

  1. Open your file, click the line number, then the comment icon.
  2. Type your comment and click Add single comment.

Review editor changes

  1. Open your file and click History.
  2. Click a commit to see green (added) and red (removed) lines.

No secrets: Never share your password. Invite your editor as a collaborator instead.

Step 4: Publishing a Free Author Site

Create your site repository

  1. Create a new repository named exactly yourusername.github.io.
  2. Make it Public (required for free GitHub Pages).
  3. Click Create repository.

Add your homepage (index.html)

  1. Click Add file → Create new file. Name it index.html.
  2. Paste your HTML, edit your name and bio.
  3. Commit with message Add author homepage.

Turn on GitHub Pages

  1. Settings → Pages. Source: Deploy from a branch, Branch: main.
  2. Save. Wait a minute. Your site is live at https://yourusername.github.io/.

What not to post: home address, phone number, passwords, API keys. Your site is public.
